# olympics-glm-modeling

Archived code for a short project I did in 2021 using generalized linear modeling to predict medal outcomes in the 2021 Tokyo Olympics. You may find the corresponding Medium article I wrote describing this project here: https://medium.com/data-science/going-for-gold-predicting-medal-outcomes-in-the-olympics-using-generalized-linear-modeling-e6e9d4837ae8.
